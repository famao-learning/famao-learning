# 课本意象视频

把一篇课文里的金句做成 20–45 秒的氛围短片：真实课本页面摊开在暗色背景上，旁白念到哪里荧光笔划到哪里，课文和插图里的意象从书页里“立起来”。

已做过两条：《丁香结》（宗璞，六上）和《匆匆》（朱自清，六下）。`assets/template/` 是《匆匆》的完整工程，新片子从它改。

## 核心原则（按优先级）

1. **先具象化书中的意象，再谈加工。** 画面元素只能来自两处：这一页的插图，和课文里写到的景物。动手前把跨页插图裁出来，逐个列出意象清单（《匆匆》：垂柳、两只燕子来自插图；桃花、朱自清来自课文）。清单上的每一项都要在 3D 里出现并且显眼，缺一项就是没做完。不要另外设计课本里没有的东西。
2. **造型要像原插图。** 意象的素材以插图裁图为参考去生成，保持同一画风、颜色和细节（《匆匆》的燕子：蓝黑头背、栗红喉、白腹、灰褐翅、长叉尾，水彩质感）。相似是底线，在相似的基础上再优化。不要用几何体拼。
3. **“独立出来”要做完整。** 意象从书页上离开后，书页上印着的那个要消失（燕子起飞后，页面上的燕子淡出）。
4. **氛围感是这类视频的命。** 暗背景、暖色主光、浅景深、缓慢运镜、飘落的花瓣和叶子、黄昏转场、月亮。但加工不能盖过第 1 条。
5. **画面和文字要平衡，用运镜来平衡。** 不要一个构图用到底：念到一句先落在字上（划线句清晰可读），意象出现时抬起去看意象，再回到字上。文字不需要全部展示，划线的那几行读得清就够；也不能为了意象让字完全看不清。
6. **人物立绘要坐正。** 始终竖直、正对镜头，是那一段的画面主体，可以挡住少量文字；不要为了让字让位把人物歪到页角或向后仰。
7. **旁白要有感情、合情境、引人入胜。** 文案直接引用课文原文金句，不改写。详见“旁白”一节。
8. **缺素材主动去找。** 课本页面、参考图直接联网下载或生成，不用自制占位内容交差。

## 流程

### 1. 定课文和金句
- 确认课文、年级册次，选 3–5 句原文金句，总长 60–150 字（约 20–45 秒）。
- 金句必须都在同一个跨页上（要划线）。结尾优先用课文自己的句子，不自编口号。

### 2. 下载课本页面
```bash
python3 scripts/fetch_textbook.py find 语文 六年级 下册
python3 scripts/fetch_textbook.py pages <课本id> 1,44-50 <工程>/assets/book
```
- 序号是预览图序号，不是页码；多下几张拼个总览图，看图确认哪两张是目标跨页，再下前面几页当翻页用。
- 偶数序号通常是右页，奇数是左页（以实际图为准）。
- 页面上的出版社水印保留，不要去掉，也不要用生成图整块覆盖有水印的区域。

### 3. 清点意象、准备素材
1. 把跨页顶部/插图区裁出来看（`ffmpeg -vf crop`），写出意象清单，每项注明来源（插图 / 课文）和它在页面上的像素位置。
2. 逐项准备素材。这台机器上 `codex exec` 自带生图：
   ```bash
   codex exec --skip-git-repo-check -s workspace-write -i 参考裁图.png - < 提示词.txt
   ```
   `-i` 会吞掉后面的参数，提示词必须从标准输入给。提示词里写明：以附图为画风和造型参考、纯白底、无阴影、无文字、主体完整留边、保存为 `./xxx.png`。
   - **会动的东西**（鸟、蝴蝶）：生成 2×2 四个姿态的精灵图（翅膀高举 / 半举 / 平展 / 下压，同一只、同朝向）。
   - **成排的东西**（柳条、藤蔓）：一张图里并排 5 条，竖直垂下，中间留白。
   - **人物**：全身、坐姿或站姿、四分之三侧面、写实 3D 质感、柔和暖光、纯白底。历史人物只取时代气质，不保证像本人，交付时说明。
3. 抠图（模板里的脚本）：
   - `cutout.py`：白底人物，按“越白越透明”抠，能抠出藤椅镂空。
   - `sprites.py`：鸟按“与边缘连通的白色”抠（保住白肚子），四帧按眼睛位置对齐排成一行；柳条按非白抠并自动切列。
   - `patches.py`：把印在书页上的动物擦掉，生成羽化补丁。用周围底色平滑填补，不要用整块生成图去盖（对不齐，还会盖掉水印）。
4. 每个素材抠完都叠在深色底上看一眼再用。

### 4. 旁白
- 用 `elevenlabs-voiceover` skill 的规矩：`eleven_v4`、Text-to-Dialogue、`language_code: zh`、`stability: 0.5`、整段一次生成。模板里的 `tts_el.py` 已按这个写好，同时输出逐字时间。
- 音色默认 **Stacy**（用户在 Stacy / Macy / Nydia 里选定的）。不要用微软晓晓等播报型 TTS，也不要用男声配稀疏钢琴，这两种都被否过。
- 文本里用英文情绪标签按句子的情境写表演提示，一句一个情绪，整体由轻到重再收：
  ```
  [softly, wistful, unhurried] 匆匆。朱自清。
  [gentle, flowing] 燕子去了，有再来的时候；……[tender, questioning] 但是，聪明的，你告诉我……
  [quiet, a little lost] 我不知道他们给了我多少日子……
  [low, pensive] 我赤裸裸来到这世界……[with feeling] 但不能平的……
  [softly, lingering] 你聪明的，告诉我……
  ```
  在该停的地方加逗号、省略号制造停顿；叹息类标签（`[gentle sigh]`）每条最多一处。
- 生成后用 whisper 转写核对有没有读错字（`whisper-cli -m ~/fund/models/ggml-large-v3-turbo.bin -l zh`），多音字（如“解”）单独留意。
- 我听不到声音：感情够不够只能请用户听。拿不准时同一段文字出 2–3 个音色的带配乐试听，让用户挑。
- `build_vo.py` 把逐字时间转成 `src/vo.js`：每组划线的逐字时间、关键词出现的时刻（`marks`，动画都挂在这些时刻上）、字幕。

### 5. 搭场景
从 `assets/template/` 复制一份，`npm i`，改 `src/content.js`（页面序号、划线行坐标、人物和动物的位置）和 `src/main.js` 里的意象部分。技术细节、坐标换算、每个元素怎么做见 [references/scene.md](references/scene.md)。

时间线的骨架：
1. 0–2 秒：书翻开，俯视全书，顶部标题“篇名 · 作者”。
2. 第一句开始：镜头落到划线的那一行；意象依次出现，每个意象挂在旁白念到它的那一刻（念“燕子去了”燕子起飞，“杨柳”柳枝落叶，“桃花谢了”落花）。
3. 中段：镜头在文字和意象之间来回。
4. 情绪转折处（通常是“我……”的自述）：作者立绘从书页升起，光线转黄昏。
5. 最后一句：镜头回到划线句；结尾拉开成全景（书、人、意象、月亮），呼应开头的意象（燕子飞回）。

### 6. 预览、渲染、混音
```bash
./stills.sh 5,9,13,21,27,33,40      # 抽帧拼图，每改一轮都看
node render.mjs --video out/master.mp4          # 约每 100 帧 45 秒，放后台跑
BGM=/Volumes/素材库/BGM/某曲.mp3 BGM_START=0.8 ./mix.sh out/master.mp4 out/成片.mp4
```
- 配乐从 `/Volumes/素材库/BGM/` 里的抖音热门曲选（目录里有《BGM适用场景说明.md》），要纯器乐段够长；用 `silencedetect` 找起点。古风文用古风曲（《此生不换》前奏），抒情散文用钢琴（《夜的钢琴曲五》）。
- 混音目标（按参考原片测得）：音乐铺满、几乎和人声一样响，整体约 −14 LUFS、起伏 LRA ≈ 2；人声加一点混响和高频空气感。`mix.sh` 已按这个调好。
- 成片再抽一遍帧核对后才交付。

## 交付时要说明
- 成片路径、时长；意象清单逐项对应到画面里的什么。
- 我听不到声音，请用户试听旁白的感情和配乐。
- 人物是生成图，不保证像本人；课本页面保留着出版社水印；配乐是商用歌曲，发抖音时在平台曲库里挂同一首。
- 没做好或没验证的地方照实说。

## 踩过的坑
- 用几何体拼燕子、自己编柳条 → “少了课本中的意象”。素材一律以插图为参考生成。
- 为了看意象把镜头抬高、景深开大 → 字看不清；反过来把字铺满 → 意象被挤出画面。两头都被否，解法是运镜来回。
- 把人物立绘转角度、后仰、挪到页角给文字让位 → “歪了”。人物只做绕竖轴朝向镜头，不倾斜。
- 黄昏主光放在人物正后方 → 柳枝的影子横扫正文。放侧面，让影子落在没有划线的区域。
- 落花落叶的落点要避开划线的那几行，落在标题和插图一带。
- 意象挂得太高 → 近景里根本看不到。柳条要垂到书页上沿（离页面 0.1–0.3），桃枝压到页面左上角上方 0.1–0.2。
- 生成图去掉动物后直接贴回页面 → 柳枝对不齐、水印被抹掉。只做小块羽化补丁。
- 渲染一遍十分钟：先用抽帧把构图定死再渲整片；改主意时先 `pkill -f "render.mjs --video"`。
