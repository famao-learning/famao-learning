# 场景怎么搭（assets/template 说明）

模板是《天净沙·秋思》的完整工程，带素材，复制出来 `npm i` 就能跑。Three.js r170，所有动画都是时间 `t` 的纯函数，`window.renderFrame(frame)` 出一帧；`render.mjs` 用 puppeteer-core 驱动系统 Chrome 逐帧截图，管道给 ffmpeg。成片只出 3:4 竖版（1080×1440）；`--fmt 169` 的 16:9 横版开关还在代码里，但用户已定“只做 3:4”，不要主动用。

`assets/examples/congcong/` 是更早的《匆匆》横版工程的代码（没有素材、没有竖版和艺术字幕），只用来抄元素写法：成排垂柳、桃枝生长开花、作者坐像、擦掉印刷燕子的补丁、月亮。

## 文件

| 文件 | 作用 |
|---|---|
| `src/content.js` | 可替换的内容：时长、标题、页面尺寸和序号、划线行坐标、红印文字、每句字幕的字号 |
| `src/pages.js` | 把 `assets/book/N.jpg` 做成书页贴图（书脊压暗、纸纹） |
| `src/main.js` | 整个场景：书、翻页、荧光笔、各个意象、灯光、后期、运镜、标题和字幕 |
| `src/index.html` | 画布和文字层的样式（标题、字幕、底部暗角；`.f34` 是竖版的字号和位置） |
| `src/vo.js` | `build_vo.py` 生成，不要手改 |
| `src/cover.html` | 封面排字页（`?r=34` 竖版 / `?r=43` 横版） |
| `tts_el.py` | 读 `audio/vo_text.txt`，生成 `audio/vo.mp3` 和逐字时间 json。不带参数用默认音色华风；也可以传音色名开头或 voice_id、输出名 |
| `build_vo.py` | 逐字时间 → `src/vo.js`。换书时改里面的 `QUOTES`（划线原文）、`MARKS`（关键词）、`SUBS`（每句字幕） |
| `prep.py` `cutout.py` `sprites.py` `patches.py` | 抠图与补丁，需要 numpy、pillow、scipy（在临时 venv 里装） |
| `render.mjs` `stills.sh` `mix.sh` | 渲染、抽帧拼图、混音 |
| `cover.mjs` | 封面底图渲染和排字截图 |

素材放哪：`assets/book/N.jpg` 页面，`assets/*.png` 抠好的意象（模板里是 tree、bridge、house、man3d、horse3d、vine、crow、perch），`audio/vo_text.txt` 旁白稿，选定的配乐也复制到 `audio/`。

## 坐标

- 书：左右页各宽 1、高 1.414，书脊在 x=0，页面顶边 z=−0.707，y 向上。镜头在 +z 一侧朝 −z 看。
- 页面像素 → 世界：`toW(side, px, py)`，`side` 右页 1 / 左页 −1；页面图的像素尺寸写在 `content.js` 的 `PAGE` 里（模板是 1847×2610）。
- 划线行：先用投影法找出每行的中心 y 和左右 x（对页面灰度图按行统计深色像素）。`HL` 里每组写 `quote`（含标点和注释角标的原文）和 `lines: [起点x, 终点x, 行中心y, 这一行的原文]`。
- 意象的位置写在 `POS`（世界坐标 x, z），出现时刻写在 `T`，都挂在 `VO.marks` 上。

## 各元素的做法

- **荧光笔**：贴在页面上的条形面片，正片叠底混合，着色器画出毛边，进度由该组逐字时间驱动（提前 0.08 秒）。
- **立牌**（`makeCutout`：老树、小桥、人家、瘦马、断肠人）：生成图抠出来的一张竖直面片，从书页上长出来，`MeshBasicMaterial` + `alphaTest` + `alphaToCoverage`，每帧只绕竖轴转向镜头，不倾斜。影子用一张只投影不显示的面片，始终正对主光，侧光下也是完整剪影。`sway` 让它随风摆，`ripple` 是出现时脚下的一圈光波。
- **贴在书页上的带子**（`ribbon`：流水、古道）：沿一条曲线铺开的面片，正片叠底，着色器画水纹或土路，`uP` 控制从一头流到另一头。绕着划线的字走，不压字。
- **垂下来的枝条**（枯藤；《匆匆》里是垂柳）：每条是一张多段面片，贴图集里的一列，每帧改顶点做摆动。从画面上方垂下来，竖版里正好填满多出来的天空。
- **飘落物**（枯叶；《匆匆》里是花瓣）：实例化粒子，先零星飘落，起风后横着卷过书页；落点避开划线行。
- **鸟**（昏鸦；《匆匆》里是燕子）：一张面片 + 四帧图集（改 `offset.x` 换帧，夹杂滑翔），沿 CatmullRom 曲线飞，面片朝向镜头，按屏幕上的前进方向翻转和俯仰；落定后换成停栖的姿态。
- **夕阳与晚霞**：远处的日轮和一片加色混合的霞光，随旁白下沉。
- **黄昏**：主光位置、颜色、强度随 `dusk` 插值到侧面的低位暖光，背景变暖，立牌贴图同步染一点暖色；念完后 `night` 让天色再暗下去。
- **后期**：RenderPass → BokehPass（光圈 0.004–0.0075，大了字就糊）→ OutputPass → 暗角/颗粒/淡入淡出。

## 运镜和竖版取景

`KEYS` 是一串 `{t, p 机位, q 注视点, e 缓动, r 竖版取景框}`，时间都挂在 `VO.marks` 上，换了旁白会自动跟着走。对焦距离默认取机位到注视点的距离。

机位坐标沿用横版 16:9 的参考画面（竖直视角 32°，水平约 54°），这只是摆机位用的坐标系，成片仍然只出 3:4。竖版不另外摆机位，而是在同一个机位上换取景框：

- `r: [中心x, 中心y, 宽]`，单位是横版 1920×1080 画面的像素；高 = 宽 × 4/3。取景框可以超出横版画面，往上超出的部分就是多出来的天空。实现是离轴投影（`applyView`），是真渲染，不是裁切。
- 不写 `r` 时用默认的 `R34 = [960, 430, 1440]`：取横版中间 75% 的宽度，上方多露一大片天。相邻关键帧的取景框会插值。
- 常用的改法：
  | 镜头 | 取景框 | 原因 |
  |---|---|---|
  | 俯视跨页 | `[960, 600, 1680]` | 跨页是横的，放宽才能完整；中心下移让书居中，给左下角标题留位置 |
  | 划线句特写 | `[960, 430, 1680]` | 一行字很宽，放宽保证整行在画面里 |
  | 字在画面偏左 | `[800, 430, 1640]` | 中心左移 |
  | 人物和动物并排 | `[1250, 430, 1560]` | 中心右移，把横版里出画的部分也收进来 |
  | 结尾全景 | `[1120, 430, 1760]` | 放宽 |
- 判断标准：划线的整行、当前这句的意象主体都要完整在画面里；每改一轮都 `./stills.sh` 看。

可直接套用的几种机位（以左页第一段、右页人物为例）：

| 用途 | 机位 p | 注视点 q |
|---|---|---|
| 俯视全书 | (0, 2.9, 0.5) | (0, 0, 0) |
| 读字 | (−0.7, 0.5, 0) | (−0.7, 0, −0.42) |
| 抬头看意象 | (−0.64, 0.48, 0.5) | (−0.75, 0.18, −0.63) |
| 字 + 贴在页面上的意象 | (−0.58, 0.52, 0.08) | (−0.6, 0, −0.4) |
| 人物主体（低机位） | (0.52, 0.3, 0.72) | 人物胸口 |
| 结尾全景 | (0.92, 0.44, 1.2) | (−0.12, 0.17, −0.3) |

人物会挡住他身后的字：把人物放在划线句的右前方，只挡句尾。

## 标题和字幕

都是画布上面的 HTML 层，随 `renderFrame` 逐帧更新，截图时一起拍进去。

- **样式**：左下角；字体是钟齐志莽行书（`assets/fonts/ZhiMangXing-Regular.ttf`，SIL OFL 开源字体，用户选定），在 `index.html` 里用 `@font-face` 载入，`--art` 是字体、`--artw` 是字重；奶白色字加柔和的黑色投影。想试别的字体：把字体文件放到 `assets/fonts/`，渲染时加 `QS="sf=名字&sw=400&sfu=文件名.ttf"`。行书里个别字偏草（如“昏鸦”），放大看一眼读不读得出。
- **错落**：每个字一个 `span`，字号倍数写在 `content.js` 的 `SUB_SIZES`（按句子顺序，一句一组，0.84–1.24 之间交错），高低和倾斜由 `artChars` 加一点确定性的抖动。
- **逐字出现**：`build_vo.py` 给每句字幕写出逐字时间，`artPose` 让每个字在念到它时从模糊、略大、略低的状态落定。
- **红印**：标题后面盖作者名，最后一句后面盖 `SEAL`（如“秋思”），在句子写完后“盖”上去。
- **水墨晕开**（`makeInk`）：退场不用淡出。每句一个 SVG 滤镜：低频噪声位移让边缘像被水带歪，高斯模糊加透明度增益让笔画向外洇、变粗变软，再用另一层噪声做蒙版一片片“吃掉”，最后整体淡去。从每句结束前 0.4 秒开始，持续约 1 秒（`INK_HOLD`、`INK_DUR`），最后一句慢 45%。每句是独立的一层，所以上一句还在晕散时下一句可以开始写。
- **暗角衬底**（`#shade`）：底部一层渐变压暗，保证亮页面上白字读得清；黄昏后自动减弱。字幕层必须在暗角层上面。
- **英文译文**：默认关（`SUB_EN = false`）。要开时把译文写在 `TITLE_EN` 和 `build_vo.py` 的 `SUBS` 第二项里。
- 最后一句的停留时间在 `build_vo.py` 末尾单独加了 1.4 秒，让红印看得清。

## 封面

底图从 3D 场景按新画幅重新渲染，取景框同样用横版画面坐标（可超出，负的 y 是往上多看天空）。主体（人物、动物）放在画面下半部，上半部的天空留给标题：

```bash
mkdir -p out/cover
node cover.mjs 22.6 560,-900,2060,1100 1080 1440 out/cover/bg34.png   # 3:4 底图：秒数、取景框、渲染宽高
node cover.mjs 24 350,-250,1950,950 1920 1440 out/cover/bg43.png      # 4:3 底图
node cover.mjs compose "src/cover.html?r=34" 1080 1440 "out/封面_3x4.jpg"
node cover.mjs compose "src/cover.html?r=43" 1440 1080 "out/封面_4x3.jpg"
```

底图只拍画布，不带字幕。排字在 `cover.html`，风格参考抖音号“梁州”的封面：

- **金句大字**：志莽行书，每个字单独定位，写在脚本里的表 `L[画幅].chars`，每项是 `[字, x, y, 字号, 倾斜角, 是否引子]`。竖版一行两三个字往下错落（引子一行小字 → 两个大字 → 一大一小 → 最后两个字最大）；横版排成一条高低起伏的横排。字号在 90–250 之间拉开差距，虚字（在、的、是）用最小的；相邻的字可以略微叠压，但不能把哪个字盖住。
- **竖排小字**：左上角，宋体，三列，放书里的其他句子。
- **说明块**：左侧中部，作者、书名、出处，小号宋体，中间一道短横线。
- **红印**：盖在金句最后一个字旁边。
- 底图整体降一点饱和度和亮度，标题背后用径向渐变压暗（矩形渐变会露出硬边）。标题不要压到人物的脸。
- 换书时改 `cover.html` 里的字表、竖排小字、说明块和印文，每改一次都截图看。不同字体的字面大小不一样，脚本里的 `K` 是按字框中心放大的倍数（志莽行书 1.2）。
